# 🐕 Бот-напоминалка про выгул собаки

Присылает напоминания в чат, кнопкой отмечает кто и когда выгулял, считает статистику и хранит историю с заметками.

## Что уже умеет

- Напоминание через N часов (по умолчанию 8) — таймер считается от **последней записанной прогулки**, а не по жёсткому расписанию
- Если через час никто не отметился — повторный мягкий пинг
- Кнопка "Я выгулял(а)" — бот сам видит, кто именно нажал (по имени в Telegram)
- Заметка к прогулке (клещ, аппетит, поведение — что угодно)
- `/stats` — статистика за сегодня и за неделю, с "медалями" кто выгуливал больше
- `/history` — последние 10 прогулок
- `/export` — вся история в CSV файле (можно открыть в Excel)
- `/setinterval` и `/setpet` — настройка под конкретное животное
- Переживает перезапуск процесса — при старте сам восстанавливает напоминания по сохранённым данным

## Шаг 1. Получить токен бота

1. В Telegram напишите **@BotFather**
2. Отправьте `/newbot`
3. Придумайте имя и username (username должен заканчиваться на `bot`, например `MyDogWalkBot`)
4. BotFather пришлёт токен — длинную строку вида `123456789:AAH...`. Сохраните её, она понадобится дальше.

## Шаг 2. Установить окружение

Нужен **Python 3.10 или новее**. Проверить версию:

```bash
python3 --version
```

Дальше в папке проекта:

```bash
# создаём виртуальное окружение
python3 -m venv venv

# активируем (Linux/Mac)
source venv/bin/activate
# активируем (Windows)
venv\Scripts\activate

# ставим зависимости
pip install -r requirements.txt
```

## Шаг 3. Указать токен

Скопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен от BotFather:

```
BOT_TOKEN=123456789:AAH...ваш_настоящий_токен
```

## Шаг 4. Запустить

```bash
python bot.py
```

В консоли должно появиться `Бот запущен, жду сообщений...` — значит всё работает.

## Шаг 5. Добавить в чат с женой

1. Создайте групповой чат в Telegram (или используйте существующий)
2. Добавьте туда бота как участника
3. Напишите в чате `/start` — бот зарегистрирует именно этот чат и начнёт отсчёт напоминаний

> Заметки к прогулке работают через "ответить на сообщение" (reply), поэтому специально отключать Privacy Mode бота через BotFather **не требуется** — бот увидит только команды и ответы на свои же сообщения, что и нужно для приватности группы.

## Как это работает каждый день

1. Бот присылает: "🐾 Время выгулять {имя}!" с кнопкой
2. Кто-то из вас нажимает кнопку — бот записывает имя и время
3. По желанию — жмёте "📝 Добавить заметку" и отвечаете текстом на запрос бота
4. Следующее напоминание бот сам поставит через заданный интервал от этого момента

## Хостинг для работы 24/7

Пока бот запущен только на вашем компьютере — он работает только когда компьютер включён и скрипт запущен. Чтобы бот работал постоянно, нужен внешний хостинг. Варианты (проверьте актуальные условия и цены — они периодически меняются):

- **Railway** (railway.app) — самый простой вариант для такого бота, есть бесплатный стартовый лимит
- **Render** (render.com) — похоже, background worker
- **VPS** (любой недорогой, например Hetzner) — больше контроля, чуть сложнее в настройке (нужен `systemd` или `screen`/`tmux`, чтобы бот работал после закрытия терминала)
- **Свой сервер / Raspberry Pi** — бесплатно, если уже есть железо, которое работает круглосуточно

На любом варианте: залейте файлы проекта, установите зависимости из `requirements.txt`, задайте `BOT_TOKEN` как переменную окружения (не коммитьте `.env` в git — он уже добавлен в `.gitignore`), запустите `python bot.py`.

## Известное ограничение

Данные хранятся в файле `dog_walks.db` рядом со скриптом. При переезде на хостинг с "эфемерной" файловой системой (некоторые бесплатные тарифы стирают диск при каждом перезапуске) история может теряться. Если увидите такое поведение — ищите тариф с "persistent disk/volume" или подключайте внешнюю БД.

## Идеи для развития (если решите продавать как продукт)

Из обсуждения — что можно добавить сверху, когда MVP обкатан на себе:

- Несколько питомцев на один чат
- Другие типы задач (кормление, лекарства) — не только выгул
- Геймификация — расширенные "достижения" за серии дней подряд
- Настраиваемый график вместо фиксированного интервала (щенкам — чаще)
- Уведомление о погоде перед прогулкой (потребует стороннего API погоды)
