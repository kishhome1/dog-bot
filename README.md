# 🐕 Barbos — Telegram Mini App для учёта выгула собаки

Напоминает семье выгулять собаку, отмечает кто и когда гулял (и сколько), считает статистику и следит за датами обработок (клещи/глистогонное/прививки). Весь UI живёт в Telegram Mini App; бот — только точка входа и канал push-напоминаний.

## Что умеет

- Онбординг в Mini App: кличка → способ напоминаний (по фиксированному времени или через N часов от последней прогулки) → инвайт-ссылка для второго участника семьи
- Отметка прогулки: длительность (с наградами бронза/серебро/золото), заметка, отметка «гуляли вместе»
- Экран «Медицина» — карточки категорий обработок со статусом и прогресс-баром
- Экран «Статистика» — прогулки за неделю/месяц/год, кто гулял чаще, награды по участникам
- Напоминания в личку каждому участнику семьи с кнопкой открытия Mini App; переживают перезапуск процесса — расписание пересобирается из БД

## Архитектура

```
Telegram Bot (bot.py)      →  /start (WebApp-кнопка) + рассылка напоминаний
        ↓ читает/пишет
PostgreSQL (Railway)       ←  FastAPI (api/main.py) — REST API + отдаёт статику Mini App
        ↑
Mini App (miniapp/, vanilla HTML/JS/CSS, без сборки)
```

Бот и API — **два независимых процесса** (на Railway — два сервиса), оба подключены к одному Postgres через `DATABASE_URL`. `bot.py` не занимается онбордингом и отметкой прогулок — это всё в Mini App поверх REST API; бот только шлёт `/start` и напоминания. Подробности — в `CLAUDE.md`.

## Шаг 1. Получить токен бота и включить Mini App

1. В Telegram напишите **@BotFather**, отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`)
2. Сохраните токен — он понадобится как `BOT_TOKEN`
3. После первого деплоя api-сервиса (шаг 4) — отправьте BotFather `/newapp`, привяжите Mini App к боту и укажите публичный URL api-сервиса (`MINIAPP_URL`)

## Шаг 2. Установить окружение

Нужен **Python 3.10+**.

```bash
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Шаг 3. Настроить `.env`

```bash
cp .env.example .env
```

Заполните:

- `BOT_TOKEN` — токен от BotFather
- `BOT_USERNAME` — username бота без `@` (нужен api-сервису для сборки инвайт-ссылки)
- `DATABASE_URL` — строка подключения к Postgres (на Railway с подключённым плагином Postgres подставляется автоматически)
- `MINIAPP_URL` — публичный адрес api-сервиса (он же отдаёт статику Mini App); локально — `http://localhost:8000`

## Шаг 4. Запустить локально

Два процесса, оба используют один и тот же `.env` из корня проекта:

```bash
# терминал 1 — бот
python bot.py

# терминал 2 — API + Mini App
uvicorn api.main:app --reload
```

Откройте `http://localhost:8000` — увидите Mini App (initData не подписан вне Telegram, поэтому реальный вход отработает только через `?dev=1` с вручную подставленной тестовой initData; полноценно приложение открывается только из Telegram).

## Шаг 5. Деплой на Railway (два сервиса)

Оба сервиса — из одного репозитория, отличаются только start command:

| Сервис | Start command | Переменные окружения |
|---|---|---|
| `bot` | `python bot.py` | `BOT_TOKEN`, `DATABASE_URL`, `MINIAPP_URL` |
| `api` | `uvicorn api.main:app --host 0.0.0.0 --port $PORT` | `BOT_TOKEN`, `BOT_USERNAME`, `DATABASE_URL` |

Подключите Postgres-плагин к обоим сервисам — `DATABASE_URL` подставится автоматически. `MINIAPP_URL` для сервиса `bot` — публичный домен сервиса `api` (Railway выдаёт его после первого деплоя).

## Как это работает каждый день

1. `/start` в боте → кнопка «Открыть Barbos»
2. Первый раз — короткий онбординг в Mini App; дальше сразу открывается экран «Сегодня»
3. Кнопка «Выгулял» → шторка с длительностью/заметкой/отметкой «вместе» → сохранено
4. Бот сам присылает следующее напоминание — по расписанию (`fixed`) или через N часов от последней прогулки (`interval`)

## Структура проекта

```
dog_bot/
├── bot.py                 # /start + рассылка напоминаний
├── database.py             # единая точка доступа к Postgres (используется и bot.py, и api/)
├── api/
│   ├── main.py              # FastAPI-приложение, роутеры + статика Mini App
│   ├── auth.py                # валидация Telegram initData
│   ├── constants.py            # интервалы обработок, пороги срочности
│   ├── schemas.py               # pydantic-модели
│   └── routers/                  # family / walks / treatments / stats
├── miniapp/                # Mini App: vanilla HTML/CSS/JS, без сборки
│   ├── index.html
│   ├── style.css
│   └── js/
├── requirements.txt
├── .env.example
└── .env                    # ваши токены и DATABASE_URL (создаётся вами, не в git)
```
